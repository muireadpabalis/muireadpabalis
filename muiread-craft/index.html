Context

Community and Civic References

Earlier public records under the name Muiread Craft include work with the Guest River Group and Guest River Restoration Project in Wise County, Virginia. This work addressed watershed planning, water quality, stream restoration, septic systems, mine-impacted land, and community participation.

This page provides a clear, current context for those references and connects them to the current primary name, Muiread Pabalis.
